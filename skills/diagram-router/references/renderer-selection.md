# Seleção do renderer

| Intenção | Skill | Renderer |
| --- | --- | --- |
| componentes, serviços e boundaries | archify-architecture | Archify |
| processo, gate, CI/CD e runbook | archify-workflow | Archify |
| chamadas, retornos e async | archify-sequence | Archify |
| origem, transformação e consumidores | archify-dataflow | Archify |
| estados, retry e cancelamento | archify-lifecycle | Archify |
| tabelas, PK/FK e cardinalidade | database-er | Mermaid CLI |
| classes, interfaces e módulos | mermaid-class | Mermaid CLI |

Quando houver dúvida entre os tipos Archify, usar o `guide` do bundle. Quando houver dois objetivos distintos, gerar dois artefatos.
